# 0002 — Расширение docker-образа Target-веткой через install.sh hook

Docker-образ Базы ставит только общий toolchain (Rust, probe-rs, gdb-multiarch) и ничего не знает про Target. Target-специфичные зависимости (rustup target add, кросс-линкер) добавляются в Target-ветке файлом `docker/target/install.sh`, который Dockerfile вызывает условно. База намеренно **не содержит** этот файл (только пустой каталог `docker/target/`), поэтому Специализация (merge Target-ветки в main, ADR-0001) лишь добавляет файл и не даёт merge-конфликтов.

**Рассмотренные альтернативы**: правка Dockerfile прямо в Target-ветке — отклонена, так как правит существующий файл и конфликтует при Специализации; отдельный Dockerfile на каждый Target — отклонён из-за дублирования общей части образа.

**Consequence**: цена — условный вызов `install.sh` в Dockerfile и пустой каталог-хук в Базе; выигрыш — чистое аддитивное расширение образа без ветвления Dockerfile.
