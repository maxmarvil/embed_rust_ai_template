# 0003 — Граница SWD-отладки: Linux — контейнер, macOS — Host

Docker Desktop на macOS не пробрасывает USB-устройства, поэтому probe-rs в контейнере там не увидит Probe. В первом заходе принято: на Linux сборка и SWD-работа выполняются в контейнере (доступ к USB через `--device-cgroup-rule` + проброс `/dev/bus/usb`), на macOS контейнер только собирает, а прошивка и GDB-сервер запускаются Host'ом. Так поддерживается обещанная поддержка macOS как Host (компиляция), но контейнерная отладка на ней явно не поддерживается.

**Consequence**: путь отладки зависит от Host и выбирается скриптом (`docker/run.sh` ветвится по `uname`); на macOS требуется probe-rs, установленный на Host. Это ограничение не видно в коде и потому зафиксировано здесь.
