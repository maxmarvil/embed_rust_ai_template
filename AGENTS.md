# AGENTS.md

Системные инструкции для ai-агентов, работающих в этом проекте.

## Контекст

Проект — шаблон окружения для встраиваемой разработки на Rust со сборкой в Docker. Термины проекта — см. [CONTEXT.md](./CONTEXT.md); модель веток и специализации — см. [docs/adr/0001-merge-based-target-specialization.md](./docs/adr/0001-merge-based-target-specialization.md).

## Правила веточной модели

- Не держать несколько таргетов одновременно: одна Target-ветка — один Target.
- Target-ветки между собой никогда не мержатся.
- Merge Target-ветки в main — одноразовая Специализация, необратимая в терминах шаблона; повторной подгрузки шаблона не существует.
- Обновления Базы в специализированный проект переносятся только вручную, по явному решению.

## Роли агентов

Роли определяются в Базе, каждой роли соответствуют права:

- **Исследование** — изучение окружения, таргетов, периферии.
- **Планирование** — составление планов работ и их разбивка.
- **Исполнение** — реализация изменений.
- **Ревью** — проверка кода и решений на соответствие стандартам.
- **Тестирование** — проверка работоспособности прошивки и окружения.

Конфигурации ролей появятся в следующих заходах; до этого агенты действуют с базовыми правами.

## Работа с устройством

- Устройство подключается к Host через Port; поиск порта выполняется через Skill с ветвлением по Host-системе (Linux: `/dev/ttyUSB*`, `/dev/cu.*`; macOS: `/dev/cu.usbmodem*`).
- Конкретная плата (Board) — забота проекта, не шаблона; конфигурации в Target-ветке выбираются по семейству.

## Ограничения

- Host: Linux и macOS. Windows не поддерживается в первом заходе.
- Не коммитить секреты, ключи и локальные пути захвата устройств.
- Не изменять Базу из проектных сессий без осознанного решения — сначала обсудить.
