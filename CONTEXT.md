# Sargassum (embed_rust_ai_template)

Шаблон окружения для разработки встраиваемых систем на Rust локально на Host (Linux/macOS) с ai-агентами.

## Language

### Шаблон и структура

**Шаблон (Template)**:
Стартовый репозиторий-комплект для проектов встраиваемой разработки; внутри себя таргеты не переключает.
_Avoid_: boilerplate, скелет

**База (Base)**:
Содержимое main шаблона: setup-скрипт, targets-шаблоны, Rust toolchain, skills-скелет, агенты, инструкция по началу работы.
_Avoid_: main, trunk

**Target**:
Семейство чипов, схожих архитектурно и периферийно (stm32f1xx, rp2040, …); каждому Target соответствует одна ветка шаблона и базовый шаблон конфигурации в `targets/<family>/`.
_Avoid_: платформа, чип

**Target-ветка**:
Ветка шаблона с конфигурациями для одного Target; подливается в main существующего проекта. Для специфических devboard допустима отдельная Target-ветка.
_Avoid_: support-branch

**Специализация (Specialization)**:
Одноразовый merge Target-ветки в main проекта. После него проект — независимый форк Базы; обновления шаблона принимает только вручную.
_Avoid_: upgrade, sync

**Board**:
Конкретная плата с прошивкой, портами и flash-процедурой. Забота проекта, не шаблона.
_Avoid_: target, устройство

**Profile**:
Пара <Target, Host> для одной сессии сборки/отладки; Target задаётся конфигурацией из `targets/<family>/`, Host определяется автоматически.
_Avoid_: конфиг, пресет, набор

### Инструменты агентов

**Skill**:
Пакет инструкций для агента, расширяющий его умения; ветвление по Host-системе выполняется внутри Skill'а (поиск USB-порта, например).
_Avoid_: скрипт, плагин

**Agent**:
Роль из Базы (исследование, планирование, исполнение, ревью, тестирование); каждой роли соответствуют права.
_Avoid_: воркер, модель

**Host**:
Машина, на которой выполняются сборка и отладка (локально, без Docker). В первом заходе — Linux и macOS; Windows вне скоупа.
_Avoid_: система, ОС

**Port (SerialPort)**:
Точка подключения устройства на Host, которую находит Skill (отличается по ОС: /dev/ttyUSB*, /dev/cu.usbmodem*, …). Несёт UART; не путать с Probe.
_Avoid_: COM, tty

**Probe**:
Устройство SWD-отладки (ST-Link и подобные), подключаемое к Host по USB. Отдельный канал, не Port.
_Avoid_: щуп, программатор, отладчик
